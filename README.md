# Customer Churn Prediction & Customer Segmentation

A portfolio-ready Data Science project demonstrating data engineering, exploratory data analysis, machine learning, customer segmentation, and an interactive application.

## Project Objectives
- Clean and preprocess customer data.
- Explore factors associated with customer churn.
- Train and compare classification models.
- Predict customers likely to churn.
- Segment customers using K-Means clustering.
- Provide business-oriented insights.
- Maintain the project using Git/GitHub.
- Provide a RapidMiner workflow companion.

## Technology Stack
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Jupyter Notebook, Streamlit, Git/GitHub, RapidMiner.

## Planned ML Workflow
1. Load data
2. Validate and clean data
3. Exploratory data analysis
4. Feature engineering
5. Train/test split
6. Train baseline and tree-based models
7. Evaluate with accuracy, precision, recall, F1 and ROC-AUC
8. Select a model
9. Generate churn predictions
10. Perform customer segmentation
11. Deploy a simple Streamlit interface
